#  Amazon Product Purchase

##  Project Description
This project is an end-to-end test automation framework built using **Robot Framework** and **Selenium** for testing an e-commerce application (Amazon-like flow).

---

##  Features
- End-to-End Product Purchase Flow
- Page Object Model (POM) structure
- Reusable Keywords
- Cross-browser support
- Jenkins CI/CD integration

---

##  Tech Stack
- Robot Framework
- SeleniumLibrary
- Python
- Jenkins
- Git
